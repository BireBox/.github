Microsoft Edge is a browser usually made after Internet Explorer was shut down.
BireBox is a browser based on Microsoft Edge for compatibility and features.

## What features does BireBox have?
- Brand new extensions on the Web Store
- New DevTools layout
- Way more features than original Microsoft Edge!
- early support with BireBox Sync which is a repo [here](https://github.com/BireBox/BireBox-Sync)

## Why does BireBox exist?

- To build a haven for developers who don't want to get restricted by "compatibility".
- To build stronger capabilities of features.
